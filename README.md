🚀 Task Management App
A modern and interactive Task Management Web Application that helps users organize, track, and manage their daily tasks efficiently.
The application provides an intuitive interface to add, edit, delete, sort, and export tasks while supporting dark mode and analytics visualization.
This project demonstrates frontend development using JavaScript and modern UI tools.

#Features
Add new tasks with details
Edit existing tasks
Mark tasks as completed
Delete tasks
Search tasks instantly
Sort tasks by priority or date
Export tasks as JSON
Dark mode support
Task statistics visualization

# Tech Stack

### Core Technologies
- HTML5
- CSS3
- JavaScript (Vanilla JS)

### UI & Styling
- Bootstrap
- Font Awesome
